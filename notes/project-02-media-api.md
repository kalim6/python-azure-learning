# Project 02 - Media API

## Goal

Build an Azure Function API that returns information about movies and TV shows.

## Reinforce Learning

- Git branches
- Pull requests
- Azure Functions
- HTTP triggers
- Query parameters
- HttpRequest
- HttpResponse

## New Learning

- Dictionaries
- Nested dictionaries
- Data lookups
- Validation

## Example Requests

/api/media?id=1

/api/media?id=2

/api/media?id=99

## Expected Behaviour

Valid item:
- Return details

Invalid item:
- Return "Media not found"

Missing id:
- Return validation message
